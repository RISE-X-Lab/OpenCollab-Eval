# Duo 文件证据

[English](../g22-file-evidence.md) | **简体中文**

Duo 由 OpenCollab 提供，统一入口为 `duo`。通用任务角色沿用双候选生成、
机械选择、结构化裁决校验、保守回退和候选采用。裁决者通过
`read_candidate_evidence` 读取完整证据文件。
从 `opencollab.builtin_workflows` 导入 `duo` 即可使用。

可选工作流参数 `candidate_evidence_dir` 指定证据保存的父目录，建议位于运行的产物目录中。每次裁决都会建立独立子目录。省略该参数时，程序创建并保留系统临时目录，将其位置写入工作流日志。归档时应同时保存这个目录和工作流轨迹。

每个候选都保存逐字节对应的 UTF-8 `candidate.diff`、JSONL 索引和公开命令及测试记录，并将模型结果报告单独标注保存。索引行记录原始路径、文本或二进制类型，以及完整差异中的字符范围。二进制补丁、权限变化、删除记录和缺少末尾换行的状态均保留在证据中。A/B 共用的公开记录另存一份文件。

工具在工作流宿主机读取已登记的证据。裁决环境即使位于隔离容器，也能通过工具访问这些文件。工具提供只读能力，可访问范围由这次裁决的证据集合决定。候选控制的文件名作为索引数据保存，与宿主机读取路径分开。

读取使用 Unicode 字符偏移，返回内容、`next_offset` 和 `eof`。单次响应最多返回 32,768 个字符，使工具消息保持适当大小，也覆盖只有一条巨大长行的文件。裁决角色可以继续读取，累计读取量没有上限。填写裁决结构时应引用索引中的原始变更路径。

运行证据与轨迹随实际采用的候选一起保存。选择结果记录候选采用情况，基准成绩由评测器按原测试和原资源判定。

# 可信候选构造

[English](../../design/trusted-candidate-construction.md) | **简体中文**

候选身份由评测器的基线和 Solver 最终可见的文件系统共同决定。发布候选使用
控制器持有的 Git 配置、引用、对象与索引，Solver 工作区中的 Git 状态作为
开发工具状态保留。

## 基线权威

Solver 开始执行前，评测器根据数据集基准版本创建一个匿名基线提交。Solver
获得便于开发的单提交 Git 仓库。控制器在 Solver 运行环境的挂载之外另行保留
Git 目录，保存可信基准树。

基线证据记录数据集提交、匿名提交、基准树、工作区摘要、任务镜像身份和已同步
运行时身份。准备后的 Solver 工作区清除了远端、未来提交、替换引用、引用
日志、宿主机未跟踪文件、旧结果和其他任务产物。

## 候选投影

Solver 退出后，评测器回收当前任务持有的完整进程集合，并要求工作区稳定
静止。候选构造随后根据可信基准树创建新的临时索引。

已跟踪文件的修改和删除从最终工作树加入索引。未跟踪路径按 NUL 分隔的字面
名称枚举，并在打开候选文件前按可信基线的忽略规则分类。Solver 对
`.gitignore` 和 `.gitattributes` 的修改可作为普通候选变更提交，其他路径
的选择和字节提取仍使用控制器的规则。

Git 生成候选树、二进制完整索引补丁、变更路径清单、文件模式和补丁 SHA-256。
共享的补丁到树投影使用相同基准树，验证提取后的过滤结果和各外部 Solver
附带的候选证据。

普通文件、二进制文件、删除、符号链接和可执行位变化使用 Git 原生表示。硬
链接转换为独立普通文件。FIFO、套接字、设备文件、向外部逃逸的链接、不可读
候选文件，以及无法重建的 Gitlink 替换，会使当前任务失败。

## 忽略内容与残留状态

缓存、日志和构建输出按忽略规则留在候选之外，并在读取前完成分类。忽略路径
中的失效链接、FIFO、root 所有的条目或模式 `000` 因此保持为忽略内容。

可读取的答案残留、未来 Git 状态、宿主机文件、其他任务输出和已跟踪的基线
漂移都需要检查。可恢复残留从一次性任务副本中删除，净化状态在 Solver 启动
前再次验证。

## 官方评测绑定

官方评测器从全新任务镜像或全新基线工作区启动，应用发布的精确补丁，重新计算
评测补丁 SHA-256 与候选树，并要求它们与生成阶段证据一致。

终态记录绑定任务身份、记录标识、运行身份、数据集基线、匿名基线、基准树、
候选树、生成与评测补丁 SHA、运行时源码树、镜像标识、目标计划、执行证据和
清理结果。评测结果归属于这份绑定的候选。候选构造与 P、F、E 报告的关系参见
[评测完整性](../evaluation-integrity.md)中的判定和状态表。

## 故障范围

不可读或无法表示的候选、镜像异常和无法静止的任务进程会使对应任务失败。
暂停批次需要共享 Docker、存储、队列或已同步运行时的直接探测失败，故障范围
依据探测证据确定。

## 验证

表驱动测试覆盖已跟踪修改与删除、未跟踪和忽略文件、忽略规则变更、不可读
缓存与候选文件、二进制文件、链接、模式、硬链接、特殊文件、Gitlink、嵌套
仓库、Solver Git 变更和后台延迟写入。

确定性 Docker 实跑验证可恢复残留能够净化、可读答案残留被阻断、持续写入进程
无法发布候选，以及任务失败保持各自的影响范围。

完整性覆盖台账将每项已实现要求映射到精确回归测试。参见
[评测完整性](../evaluation-integrity.md)和
[机器可读台账](../../integrity-coverage.json)。
